

<h2>Descrição</h2>
<p>O <strong>Planilhas Diversas com Excel</strong> é um repositório que reúne diversos modelos de planilhas criadas para fins educacionais, profissionais e organizacionais. As planilhas abordam diferentes temas como controle financeiro, organização de tarefas, relatórios automatizados e dashboards.</p>

<h2>Funcionalidades</h2>
<ul>
    <li><strong>Planilhas Financeiras</strong>: Controle de despesas, receitas, orçamento mensal e fluxo de caixa.</li>
    <li><strong>Relatórios Automatizados</strong>: Uso de fórmulas e recursos como Tabela Dinâmica e PROCV/XLOOKUP.</li>
    <li><strong>Dashboards Visuais</strong>: Gráficos e painéis interativos para visualização de dados.</li>
    <li><strong>Organização de Tarefas</strong>: Modelos para controle de atividades, projetos e prazos.</li>
    <li><strong>Recursos Avançados</strong>: Aplicação de formatações condicionais, validação de dados e macros (VBA em alguns casos).</li>
</ul>

<h2>Tecnologias Utilizadas</h2>
<ul>
    <li><strong>Microsoft Excel</strong>: Ferramenta principal utilizada na criação das planilhas.</li>
    <li><strong>Fórmulas e Funções</strong>: SOMASE, SE, PROCV, ÍNDICE, CORRESP, XLOOKUP, entre outras.</li>
    <li><strong>Tabelas Dinâmicas</strong>: Para resumos e análises de grandes volumes de dados.</li>
    <li><strong>Gráficos</strong>: Coluna, pizza, linha, combinação e velocímetro.</li>
    <li><strong>Macros e VBA</strong> (em alguns arquivos): Automação de tarefas repetitivas.</li>
</ul>

<h2>Como Utilizar</h2>
<ol>
    <li><strong>Clone o repositório</strong>: <code>git clone https://github.com/MatheusTSS/Planilhas-Diversas-com-Excel.git</code></li>
    <li><strong>Abra os arquivos .xlsx</strong>: Use o Microsoft Excel para visualizar e interagir com as planilhas.</li>
    <li><strong>Insira seus dados</strong>: Substitua os exemplos pelas suas informações para utilizar os modelos.</li>
    <li><strong>Personalize conforme necessário</strong>: Adapte fórmulas, gráficos e layouts de acordo com sua necessidade.</li>
</ol>

<h2>Requisitos</h2>
<ul>
    <li><strong>Microsoft Excel</strong> instalado (preferencialmente versão 2016 ou superior).</li>
    <li>Permissão para ativar macros (caso utilize modelos com VBA).</li>
</ul>
